# Schriftlizenzen

Alle Schriften in diesem Ordner werden lokal ausgeliefert, es gibt keine Anfragen an fremde Server.
Jede Datei ist die variable Fassung (Achse wght) mit der Latin-Teilmenge, eingesetzt werden die Gewichte 400 bis 700.
Bezogen wurden die Dateien unverändert aus den npm-Paketen von Fontsource.
Alle vier Schriften stehen unter der SIL Open Font License, Version 1.1 (OFL-1.1). Der vollständige Lizenztext steht unten.
